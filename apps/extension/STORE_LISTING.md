# ZipKit - Chrome Web Store Listing

## Extension Name

**ZipKit**

## Short Description (132 characters max)

Zip. Unzip. Pack. Unpack. Inspect. Scan. A modern browser-based archive utility with built-in security scanning.

## Detailed Description

**ZipKit: The Modern Archive Utility for Your Browser**

Create, inspect, and extract ZIP, TAR, and GZIP archives directly in Chrome—with powerful security scanning built in.

**✨ KEY FEATURES**

**Archive Creation**
• Create ZIP, TAR, and TAR.GZ archives instantly
• Drag & drop files or select entire folders
• Multiple compression levels (store, fast, maximum)
• Preserve folder structure automatically
• Real-time progress tracking

**Safe Extraction**
• Extract archives with built-in security scanning
• Browse contents before extracting
• Select individual files or extract all
• Choose custom destination folders
• Preview file tree structure

**Security First**
• Real-time security analysis on every archive
• Path traversal attack detection
• Archive bomb protection (expansion ratio checks)
• Executable and script file detection
• Nested archive alerts
• Integrity verification

**Privacy Protected**
• 100% local-first—all processing in your browser
• No cloud uploads or remote servers
• No tracking, analytics, or data collection
• Your archives stay completely private
• Minimal permissions (storage only)

**Beautiful, Modern Interface**
• Clean, intuitive design
• Dark mode optimized
• Drag & drop support throughout
• Recent archives quick access
• Modal-based workflow for clarity

**⚠️ IMPORTANT SECURITY NOTES**

ZipKit performs structural security analysis to detect dangerous archive patterns. However, it is NOT antivirus software and cannot guarantee detection of all malware. Always use ZipKit alongside your existing security tools.

**🎯 PERFECT FOR**

• Developers working with compressed source code
• System administrators managing backups
• Security researchers analyzing archives
• Anyone who frequently works with ZIP/TAR files
• Users who value privacy and local-first tools

**🔒 PRIVACY COMMITMENT**

ZipKit operates entirely within your browser with zero external communication:
✓ No remote servers
✓ No telemetry
✓ No analytics
✓ No data collection
✓ No network requests

**📦 SUPPORTED FORMATS**

Current: ZIP, TAR, TAR.GZ, GZIP
Coming Soon: 7Z, RAR, password-protected archives

**🚀 LOCAL-FIRST TECHNOLOGY**

Built with modern web standards and powered by streaming architecture for efficient handling of large archives. All compression and decompression happens locally using Web Workers to keep your browser responsive.

ZipKit is open source (MIT License). View code, report issues, or contribute at: github.com/eyuelabebe/zipkit

**🛠️ TECHNICAL DETAILS**

• Manifest V3 (latest Chrome extension standard)
• TypeScript with strict type checking
• Streaming architecture for memory efficiency
• Web Workers for CPU-intensive operations
• Comprehensive E2E test coverage

**💡 HOW TO USE**

Creating Archives:

1. Click ZipKit icon in toolbar
2. Drag & drop files or click "Create Archive"
3. Choose format and compression level
4. Save your archive

Extracting Archives:

1. Click ZipKit icon
2. Drag & drop archive or click "Open Archive"
3. Review security scan results
4. Browse contents and select destination
5. Extract files
